# 0002: RAG AI 구축을 위한 임베딩 모델 BAAI/bge-m3 사용
작성일자: 2026-09-28

작성자: 김유현
## 상태
Accepted
## 컨텍스트
LangGraph를 이용해 프로그램을 설계할때 RAG를 사용하기위해 데이터를 임베딩하여야 한다. 임베딩 모델의 선택은 LLM의 결과물 생성 정확도에 큰 영향을 미친다. 데이터의 종류에 따라 유리한 모델을 선택하여야 한다.
## 결정
BAAI(Beijing Academy of Artificial Intelligenc)의 bge-m3 모델을 해당 프로그램의 임베딩 모델로 결정한다.
## 근거
- 한국어 지원 우수: MTEB 한국어 벤치마크에서 최상위권의 검색  품질을 보여준다. 따라서 DB스키마, 쿼리 예시 데이터가 한글로 되어있는 해당 프로그램에 적합하다.
- 무료 오픈소스: 해당 모델은 무료로 사용가능하므로 비용을 들이기 힘든 해당 프로젝트에 적합하다.
- 하이브리드 검색 지원: 밀집 검색과 희소 검색을 동시에 지원하는 모델이다. 희소 검색을 통해 "그래픽 카드" 와 같은 단어를 해당 테이블에 올바르게 매칭 시킬 수 있고, 밀집 검색을 통해 사용자의 모호한 질문에도 의미적 유사도를 검색 가능하다.
## 대안
- Qwen3-Embedding 시리즈: 고성능의 임베딩이 가능한 모델이지만 GPU사용이 필요하고 밀집검색에 특화 되어있으므로 하이브리드 검색을 지원하는 bge-m3가 더 유리하다. 또한 해당 모델은 긴 텍스트에 유리하지만 본 프로젝트에서 사용하는 DB는 방대한 양의 데이터가 아니므로 굳이 무거운 모델을 사용할 필요는 없다.
- OpenAI 3-Large: API로 호출해야하며 연동이 쉽지만 API 비용이 든다.
## 결과
- 한글이 포함되어있는 스키마, 예시 데이터의 검색에 유리해진다.
- LLM이 vector데이터를 검색할 떄 input에 관련된 데이터를 검색 가능하게 한다.
