# 03. 부품 성능 점수

`modules.performance_score` (V6) 에 부품별 성능 점수를 저장한다.

- **카테고리마다 지표와 단위가 다르다.** CPU 점수와 GPU 점수는 비교할 수 없고,
  `WHERE category_id = ? ORDER BY performance_score DESC` 처럼 같은 카테고리 안에서만 쓴다.
- 값이 클수록 좋다 (모든 지표 공통).
- 지표가 없는 카테고리(메인보드)는 `NULL`.

| 카테고리 | 지표 | 단위 | 종류 |
| --- | --- | --- | --- |
| CPU | PassMark CPU Mark | 점 | 외부 벤치마크 |
| GPU | PassMark G3D Mark | 점 | 외부 벤치마크 |
| SSD / HDD | PassMark Disk Rating | 점 | 외부 벤치마크 (SSD·HDD 같은 척도) |
| RAM | 이론 메모리 대역폭 | MB/s | 스펙으로 계산 |
| POWER | 80 PLUS 등급별 50% 부하 효율 | % | 인증 기준값 |
| MONITOR | 초당 픽셀 처리량 | Mpx/s | 스펙으로 계산 |
| MAINBOARD | 없음 | — | `NULL` |

외부 벤치마크 값은 **2026-10-27 에 PassMark 사이트에서 확인한 평균값**이다.
PassMark 는 사용자가 제출한 결과의 평균이라 시간이 지나면 조금씩 바뀐다.

## RAM — 이론 메모리 대역폭 (MB/s)

```
performance_score = clock(MT/s) × 8 Byte(64bit 버스) × 채널 수
채널 수 = min(package_count, 2)   -- 일반 데스크톱은 듀얼 채널
```

64bit 메모리 버스의 최대 전송률 공식이다. 근거: JEDEC DDR4/DDR5 규격의 데이터 버스 폭(DIMM 당 64bit),
참고 [Wikipedia – DDR5 SDRAM](https://en.wikipedia.org/wiki/DDR5_SDRAM), [Wikipedia – Memory bandwidth](https://en.wikipedia.org/wiki/Memory_bandwidth).

| 제품 | 계산 | 점수 |
| --- | --- | ---: |
| DDR4-3200 16GB ×1 | 3200 × 8 × 1 | 25,600 |
| DDR5-5600 16GB ×1 | 5600 × 8 × 1 | 44,800 |
| DDR5-5600 32GB ×1 | 5600 × 8 × 1 | 44,800 |
| DDR4-3200 16GB ×2 | 3200 × 8 × 2 | 51,200 |
| DDR5-6000 16GB ×2 | 6000 × 8 × 2 | 96,000 |
| DDR5-6000 32GB ×2 | 6000 × 8 × 2 | 96,000 |

용량과 CL(레이턴시)은 반영하지 않는다. 같은 대역폭이면 용량으로 2차 정렬하는 것을 권장한다.

## POWER — 80 PLUS 50% 부하 효율 (%)

80 PLUS 인증(115V Internal 기준)의 등급별 50% 부하 최소 효율을 점수로 쓴다.
출처: [CLEAResult 80 PLUS 프로그램](https://www.clearesult.com/80plus/program-details) (인증 기관),
등급별 수치표는 [Wikipedia – 80 Plus](https://en.wikipedia.org/wiki/80_Plus), [MSI – 80 PLUS Gold vs Platinum](https://www.msi.com/blog/80-plus-gold-vs-platinum-psu-what-is-the-difference)

| 등급 | 점수 |
| --- | ---: |
| 80 PLUS STANDARD | 80 |
| BRONZE | 85 |
| SILVER | 88 |
| GOLD | 90 |
| PLATINUM | 92 |
| TITANIUM | 94 |

파워는 "성능"보다 **효율 등급**이다. 출력 용량은 이미 `power.rated_power` 에 있으므로 점수에 넣지 않았다.

## MONITOR — 초당 픽셀 처리량 (Mpx/s)

```
performance_score = 가로 × 세로 × 주사율 / 1,000,000   (반올림)
```

해상도와 주사율을 한 숫자로 합친 값으로, 외부 벤치마크가 아니라 스펙에서 계산한 값이다.

| 제품 | 계산 | 점수 |
| --- | --- | ---: |
| 오디세이 OLED G8 G80SD | 3840 × 2160 × 240 | 1,991 |
| 울트라기어 27GR75Q | 2560 × 1440 × 165 | 608 |
| 오디세이 G5 S32CG510 | 2560 × 1440 × 165 | 608 |
| DELL S2722QC | 3840 × 2160 × 60 | 498 |
| MSI G2412F | 1920 × 1080 × 180 | 373 |
| 울트라와이드 34WQ75C | 3440 × 1440 × 60 | 297 |

패널 종류(IPS/VA/OLED)와 색 정확도는 반영하지 않는다.

## MAINBOARD — NULL

메인보드는 CPU·메모리 성능을 그대로 전달하는 부품이라 공신력 있는 단일 성능 벤치마크가 없다.
점수를 만들려면 칩셋 등급(Z > B > A, X > B > A) 같은 **자체 기준**을 정해야 하는데,
출처 없는 값이 섞이지 않도록 `NULL` 로 두었다.
